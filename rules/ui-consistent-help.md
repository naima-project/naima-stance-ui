---
name: ui-consistent-help
title: "Help, where there is any, is in the same place on every page"
audience: agents
strength: must
verifiedBy: agent
---

An agent-verified convention: no check holds it, and the agent verifies it by review. Before landing a change that adds
or moves a way to get help (contact details, a help page, a chat, a self-help option) or adds a page, the agent checks
that each way of getting help the app offers appears on every page that has it in the same order relative to the rest of
the page, for instance always at the end of the header or always in the footer. The agent records the review on the item
the change lands with, as a note: `naima note <item> "ui-consistent-help: reviewed, <what it found>"`. This is WCAG 2.2
SC 3.2.6 (consistent help).

## Why

people who need help look for it where they found it last time; help that moves between pages is help they do not find,
and where help belongs depends on the app's layout, which no generic check can know.
